SW_Analyzer

This is a protocol LLA (low-level-analyzer) plugin for the Saleae Logic v2 macOS app.


The plugin will allow 2-wire bus analysis: it triggers on the falling egde marked with an "x". The squared dots mark the data bits.

The plugin shows hex data in the timeline view, and the analyzer allows timestamp (data table) and hex (terminal) copy/paste export.
